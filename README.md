# TV Links

TizenBrew module for Samsung TVs: open any website on the TV and control it from your phone.

- A cursor is injected into every page and frame, so buttons and video players can be clicked.
- A small service runs on the TV (port 8781). Open `http://<TV IP>:8781/` on the phone for the touchpad,
  scrolling, typing, back/forward, play/pause, volume and opening links.

Add in TizenBrew: Module manager → Add GitHub module → `<user>/tv-links`.
